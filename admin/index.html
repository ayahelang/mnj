Cara Kerja Tracking & QR

  1. Admin login dengan Google (admin@silverhawk.web.id) via Supabase Auth.
  2. Admin tambah driver → grant role “driver” → generate unique QR/Barcode.
  3. Driver login Google di halaman /driver → lihat QR-nya.
  4. Saat pickup: driver scan QR di lokasi barang ATAU tekan “Sudah Pickup”.
  5. Sistem cek geolocation HP driver vs koordinat gudang/barang (tolerance ~100–200m).
  6. Jika cocok → status update “Picked Up”, lokasi mulai di-track real-time.
  7. Customer buka /track.html + input nomor resi → lihat map + timeline live.

Backend direkomendasikan: Supabase (Auth Google, Postgres, Realtime, Edge Functions). Frontend sudah siap dihubungkan.
